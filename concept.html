HTTP Methods

HTTP methods tell a server what action a client wants to perform.

  • GET: Requests information from a server.
  • POST: Sends information to a server.
  • PUT: Updates or replaces information.
  • DELETE: Removes information.

HTTP Status Codes

Code Meaning
200 OK – The request was successful.
301 Moved Permanently.
400 Bad Request.
403 Forbidden.
404 Not Found.
500 Internal Server Error.

Important Key Terms

  • Client: A device or program requesting information.
  • Server: A computer that provides information.
  • Request: A message sent by a client.
  • Response: A message sent back by a server.
  • URL: The address of a resource on the internet.
  • HTTPS: The secure version of HTTP.

Example of an HTTP Request

GET /index.html HTTP/1.1
Host: example.com

This request asks the server for the index.html page.
