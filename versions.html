How HTTP Has Changed

HTTP has changed over time to make the internet faster, more reliable, and more secure.

HTTP Version Comparison

Version Year Main Improvement
HTTP/0.9 1991 Basic document requests
HTTP/1.0 1996 Headers and status codes
HTTP/1.1 1997 Persistent connections
HTTP/2 2015 Faster communication through multiplexing
HTTP/3 2022 QUIC transport protocol
