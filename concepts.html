What Is HTTP?

HTTP stands for HyperText Transfer Protocol. It is a set of rules that allows web browsers and web servers to communicate. When someone visits a website, the browser sends a request to the server. The server responds by sending information such as text, images, and videos back to the browser.

HTTP Methods

HTTP methods explain what action a browser or another client wants a server to perform.

Method Purpose
GET Requests information from a server.
POST Sends information to a server, often to create something.
PUT Creates or replaces a resource at a specified location.
DELETE Requests that a resource be deleted.
HEAD Requests response information without the response body.
PATCH Applies a partial update to a resource.

HTTP Requests and Responses

HTTP Request

An HTTP request is sent by a client, such as a web browser, to ask a server for information or to perform an action. A request can include a method, URL, headers, and sometimes a body containing information.

HTTP Response

An HTTP response is the message sent back by the server. It includes a status code, headers, and sometimes a body containing the requested information.

Common HTTP Status Codes

Status Code Meaning
200 OK The request was successful.
301 Moved Permanently The requested resource has a permanent new location.
302 Found The resource is temporarily available at another location.
404 Not Found The requested resource could not be found.
500 Internal Server Error The server encountered an unexpected problem.

HTTP vs. HTTPS

HTTP transfers information between a browser and a server. HTTPS is the secure version of HTTP. It uses encryption to help protect information while it is being transferred. HTTPS is especially important when people enter passwords, payment details, or other private information on websites.

Important Terms

Term Definition
Client A device or program that requests information from a server.
Server A computer or program that receives requests and sends responses.
URL The address used to locate a resource on the web.
Header Additional information included in an HTTP request or response.
Protocol A set of rules that allows devices or programs to communicate.
Encryption A process that helps protect information by making it unreadable without the correct key.
